# Журнал клиентов

Простое веб-приложение для тренера: клиенты в одном месте, программа, журнал подходов с весами и повторами, суперсеты и трисеты, замеры с графиками, тренировочные блоки с календарём и графиком прогресса.

Это один файл `index.html`. Установка не нужна: откройте его в браузере.

## Где хранятся данные

Данные сохраняются только в браузере на том устройстве, где вы открыли страницу. На GitHub они не попадают, между телефоном и компьютером не синхронизируются и пропадут, если очистить данные сайта в браузере.

Не храните в этом репозитории реальные данные клиентов.
